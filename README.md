# Chess Stage

> **Move the light. Wake the board.**

Chess Stage is an experimental experience that transforms light into an interface for discovery.

Rather than navigating through traditional pages, visitors explore a digital stage where each illuminated chess piece reveals a different part of my work. Every interaction uncovers another story, turning curiosity into navigation and the portfolio into an immersive experience.

Built with Three.js and HTML rendered directly inside a 3D scene, the project explores how spatial interaction, cinematic lighting, and digital storytelling can create more memorable ways of presenting design work.

---

## Experience

Instead of clicking through menus, visitors:

- Move a physical spotlight across the stage
- Reveal hidden chess pieces through light
- Discover projects through exploration instead of navigation
- Experience a portfolio designed as an interactive installation

The chess pieces act as metaphors rather than game pieces—each representing a unique project, idea, or chapter in my design journey.

---

## Built With

- Three.js
- HTML-in-Canvas Rendering

- JavaScript

- HTML/CSS

---

## Inspiration

Inspired by installation art, theatrical lighting, and interactive exhibitions rather than conventional portfolio websites.

The goal wasn't simply to recreate an effect—it was to experiment with a different way of presenting creative work.
